## 🚨 Breaking Changes & Action Required

### Claude Code v2.1.225: Critical Auth Bug in Headless Sessions
[Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.225)

**401 authentication failures** breaking headless sessions when OAuth tokens are replaced with stored login tokens. **Restart required** until gateway fix deployed. Also ships gateway spend-limit support showing cap name, reset time, and operator message in usage warnings (requires gateway v2.1.225+).

**Why it matters:** Breaks automated workflows using headless mode until restart—affects CI/CD pipelines and agent SDK integrations.

---

### Claude Code v2.1.223: 5 Permission Bypass Vulnerabilities Patched
[Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.223)

Patches **Bash command hiding** via special characters, **Unicode obfuscation** in approval dialogs, **workflow sandbox escape** via `dynamic import()`, `bypassPermissions` policy bypass, and sandboxed command startup failures on Linux. Added `owner/*` wildcard syntax for GitHub org-level marketplace policies. Fixed provider-prefixed model discovery (`vertex_ai/claude-*`, `bedrock/anthropic.claude-*`).

**Why it matters:** All 5 bypasses allow malicious or compromised workflows to execute unapproved commands—immediate update required for production use.

---

### Claude Code v2.1.222: Permission Bypass in Background Tasks & Git Isolation
[Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.222)

**PreToolUse hooks no longer bypass tool restrictions** in background tasks. Worktree-isolated sessions can no longer run destructive git commands. SendMessage now evaluates permissions before dispatch to other agent sessions. Fixed proxy connectivity timeout issues and stream idle timeout handling with custom gateways.

**Why it matters:** Background task permission bypass allowed circumventing security policies—critical for multi-agent workflows.

---

### Claude Code v2.1.221: Bash & PowerShell Permission Check Bypasses
[Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.221)

Fixed critical **Bash permission-check bypass in zsh regex conditionals** and **PowerShell path-quoting vulnerabilities**. Added sandbox credential masking via `mode: "mask"` on Linux/WSL (reads sentinel copy, substitutes real values on egress). MCP servers now connect before first turn in print mode, fixing silent tool-call failures.

**Why it matters:** Shell-level permission bypasses undermine security model—affects all shell-based workflows.

---

### Claude Agent SDK Python v0.2.129: Skill Name Validation Breaking Change
[Release Notes](https://github.com/anthropics/claude-agent-sdk-python/releases/tag/v0.2.129)

**Breaking:** Skill names with parentheses, commas, control chars, wildcards, leading `/`, or whitespace now raise `ValueError` at connect time. Replace `skills=['plugin:*']` with `skills='all'` or `Skill(...)` rules. Fixes injection vulnerability where crafted skill names could pass unchecked to CLI's `--allowedTools`.

**Why it matters:** Prevents CLI argument injection via skill names—breaks existing wildcard patterns.

---

### Claude Agent SDK TypeScript v0.3.222: Session Resume Drops User Settings
[Release Notes](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.222)

**Critical bug:** Resumed agent sessions via `query({ sessionStore, resume })` drop user settings (apiKeyHelper, env, hooks, permissions). Configuration state silently lost on resume. Update to v0.3.222.

**Why it matters:** Multi-turn agent workflows lose security policies and environment config on resume—data loss and potential security degradation.

---

### Claude Code Action v1.0.187: Credential Redaction in Published Output
[Release Notes](https://github.com/anthropics/claude-code-action/releases/tag/v1.0.187)

Adds **credential redaction in published run output** to prevent accidental secret exposure in CI logs. Scopes config snapshot to working tree files only. Fixes checkout auth cleanup when API commit signing is enabled.

**Why it matters:** Prevents secret leakage in public CI/CD logs—critical for public repositories.

---

### MCP HTTP Transport Type Field Now Required
[Claude Code MCP Docs](https://code.claude.com/docs/en/mcp)

**Breaking:** HTTP servers now require explicit `type` field (`"http"`, `"sse"`, or `"ws"`). Missing type is a configuration error in v2.1.219+ (previously showed misleading "command: expected string" error). Project-scoped `.mcp.json` servers require workspace trust to auto-approve.

**Why it matters:** Configuration errors previously masked by confusing error messages—affects all HTTP-based MCP servers.

## 🆕 New Releases

### Claude Code v2.1.224: Self-Hosted Runners & Archive Plugins
[Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.224)

**Self-hosted runners** (`claude self-hosted-runner`) enable Team/Enterprise users to run Claude Code on private machines without cloud dependency. **Archive plugin source** adds offline plugin installation from zipped HTTPS URLs with optional SHA-256 pinning—eliminates git/npm requirement. **Cross-session messaging** (`SendMessage`, `ListAgents`) allows Claude Code instances to discover and message each other with new security controls (`crossSessionInbound`, `dialogExpiry`).
