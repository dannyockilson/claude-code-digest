## 🚨 Breaking Changes & Action Required

### [Claude Code v2.1.268](https://github.com/anthropics/claude-code/releases/tag/v2.1.268)
Fixed regex bug rejecting third-party Anthropic-compatible endpoints since v2.1.265; `/cost` telemetry now accurately reflects actual spend. Critical permission fixes: deny/ask rules now correctly apply to symlinked paths (`/etc`, `/tmp`, `/var` on macOS) and unanalyzable commands (`env -C`, `eval`). Respawned agents no longer inherit untrusted agent files. **Why it matters:** Permission system was silently failing for common system paths and evasion patterns—immediate security impact if you rely on deny rules.

### [Claude Code v2.1.266](https://github.com/anthropics/claude-code/releases/tag/v2.1.266)
Fixed regression where `CLAUDE_CODE_USE_GATEWAY` environment variable incorrectly forced Cloud-gateway auth, breaking API key and custom header configurations. Variable now ignored unless paired with `ANTHROPIC_BASE_URL` and `ANTHROPIC_AUTH_TOKEN`. **Why it matters:** No config migration needed—just removes unintended auth enforcement introduced in v2.1.265.

### [MCP Python SDK v2.2.0](https://github.com/modelcontextprotocol/python-sdk/releases/tag/v2.2.0)
HTTP redirects now restricted to same-origin (scheme/host/port); cross-domain redirects fail with `MCPError`. Idle HTTP sessions expire after 30 minutes by default (disable with `session_idle_timeout=None`). OAuth `issuer` validation now enforced for legacy paths; 403 non-scope errors return to caller instead of retrying. Two new deprecation warnings: OAuth providers need explicit `issuer=` parameter, and `AuthSettings` requires explicit `validate_token_resource` choice. **Why it matters:** If your MCP servers follow redirects to CDNs or external domains, or maintain long-lived stateful sessions, these changes will break existing behavior.

### [MCP Python SDK v1.30.0](https://github.com/modelcontextprotocol/python-sdk/releases/tag/v1.30.0)
Backported same-origin redirect restriction and 30-minute idle session expiry to v1.x branch. OAuth issuer validation now enforced; client registrations cached per-issuer. 5xx/429 errors stop OAuth flow instead of falling back. **Why it matters:** Security hardening across both major SDK versions—breaking changes affect production MCP servers on older SDK releases.

### [Claude Agent SDK TypeScript v0.3.265](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.265)
Fixed critical bug where shell working directory reset on each user message—agent's `cd` commands now persist across turns as intended. Added `user_message_uuid` tracking to synthetic turns for better message lineage in complex workflows. **Why it matters:** Multi-turn sessions with directory navigation were fundamentally broken; this restores expected shell state continuity.

## 🆕 New Releases

### [Claude Code v2.1.270](https://github.com/anthropics/claude-code/releases/tag/v2.1.270)
Quick patch fixing v2.1.269 regression where read-only git commands (`git status`, `git log`) unexpectedly prompted for permission after extended runtime. **Why it matters:** Restores non-interactive git operations for developers with long-running sessions.

### [Claude Code v2.1.269](https://github.com/anthropics/claude-code/releases/tag/v2.1.269)
New `claude plugin eval` command runs plugin test suites with scored JSON + HTML reports—critical for plugin CI/CD. Added `/output-style` command to list and switch output styles across Remote Control, cloud, and headless sessions. Bash tool now shows diffs for file edits when `bashEditDiffEnabled` is set. 60+ bug fixes for prompt cache invalidation, terminal escape codes, permission rule scoping, and long-session responsiveness. **Why it matters:** Plugin developers finally have reproducible testing infrastructure; diff visibility improves auditability of Bash modifications.

### [Claude Code v2.1.267](https://github.com/anthropics/claude-code/releases/tag/v2.1.267)
Added `maxEffortLevel` setting to cap effort across Bedrock, Vertex, and Foundry providers—enforces org policy while allowing user overrides. New `--system-prompt-snapshot off` flag forces fresh prompt rendering per request for iterative prompt engineering. Fixed prompt-cache stability across subagents and resumed sessions, eliminating redundant system prompt re-rendering. **Why it matters:** Prompt engineering workflows get faster iteration; org admins gain enforcement controls for expensive extended thinking.

### [Claude Code v2.1.265](https://github.com/anthropics/claude-code/releases/tag/v2.1.265)
Plugin directory hot-reload: `--plugin-dir` now accepts folders where child folders auto-load on manifest changes—eliminates restart cycles. Subagent resume, agent teammates, and prompt prefixes now preserve prompt-cache properly, significantly improving multi-agent performance. Tool result disk cap (1GB) prevents unbounded disk consumption from large outputs. `cd` commands now persist in non-interactive sessions (`-p` stream-json, cloud). **Why it matters:** Plugin development cycle time drops dramatically; multi-agent workflows get cheaper via better cache reuse.

### [Anthropic Python SDK v1.5.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.5.0)
Tool objects now accepted directly in `messages.create()`, `parse()`, `stream()`, and `count_tokens()`—eliminates manual serialization. New `Message.to_param()` serialization helpers reduce boilerplate. Managed Agents get auto mode tool permissions; public GitHub repos mount without auth tokens. Security fixes for credentials file permissions and streaming tool input isolation. **Why it matters:** Significantly cleaner agent code by removing serialization ceremony.

### [Anthropic TypeScript SDK v0.125.0](https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/sdk-v0.125.0)
Auto mode tool permissions for Managed Agents; public GitHub repo mounting without tokens. New `content_too_large` error code for `web_fetch` tool. New `user-profiles-2026-09-04` beta with `external_user_details` support. **Why it matters:** TypeScript SDK reaches feature parity with Python for Managed Agents workflows.

## 📦 SDK & API Updates

Fixed `permission_denials` to correctly include Read/Edit/Write calls blocked by path-scoped deny rules. Added SSE transport methods to browser SDK (`getCcrEvent()`, `getSseLastSequenceNum()`) with sequence tracking and delivery updates. `systemPrompt` recording now defaults-on for custom prompts; mid-session changes take effect at next compaction. **Why it matters:** Robust streaming and recovery for browser-based agents.
