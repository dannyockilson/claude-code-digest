## 🚨 Breaking Changes & Action Required

### Claude Code v2.1.215
[Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.215)

`/verify` and `/code-review` skills no longer run automatically—you must explicitly invoke them with slash commands. Shifts from passive verification to opt-in model, eliminating unsolicited output.

**Why it matters:** If you rely on automatic code review in CI/CD or local workflows, you'll need to update scripts to explicitly call `/code-review` or `/verify`.

---

### Claude Code v2.1.214
[Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.214)

Security-focused patch addressing multiple permission bypass vectors:
- Windows PowerShell/Bash parsing edge cases and command injection (help/man/docker daemon flags) now properly gated
- Docker daemon redirect flags (`--url`, `--connection`, `--identity`) now require permission prompts
- Fixed Windows PowerShell file encoding (UTF-16LE→UTF-8)
- Added `EndConversation` tool for abuse/jailbreak handling
- OpenTelemetry correlation attributes (`message.uuid`, `client_request_id`, `tool_source`) for tracing

Breaking: single-segment `dir/**` hook conditions now match only `<cwd>/dir` (use `**/dir/**` for any-depth); `-m`/`-f` flags in `file` commands now require permission.

**Why it matters:** If you have custom hooks or permission rules using glob patterns, audit them before upgrading to avoid unexpected blocking.

---

### Claude Code v2.1.212
[Release Notes](https://github.com/anthropics/claude-code/releases/tag/v2.1.212)

Major workflow changes:
- `/fork` now creates background sessions instead of in-session spawns (use `/subtask` for old behavior)
- `/resume` opens picker for past sessions instead of inline resumption
- Runaway loop protections: WebSearch capped at 200/session, subagents capped at 200/session, long MCP calls auto-background after 2min (all configurable)
- Plan mode now prompts before auto-running file-modifying Bash
- SIGTERM during Bash properly kills process tree
- Windows PowerShell 5.1 Group Policy blocks now fall back to PS7
- Symlink worktree security vulnerability patched

**Why it matters:** Scripts using `/fork` or `/resume` programmatically need immediate updates; runaway loop caps may require tuning for heavy automation workflows.

---

### MCP TypeScript Client v2.0.0-beta.4
[Release Notes](https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/%40modelcontextprotocol/client%402.0.0-beta.4)

Response cache now serializes to JSON instead of `structuredClone`, fixing silent caching failures in Jest+jsdom and Node <17. Cache writes now fail loudly if unserializable. Schema modules moved to shared `@modelcontextprotocol/core` dependency.

**Why it matters:** If you're caching non-JSON-serializable objects (e.g., functions, symbols), your cache will now throw instead of silently failing.

---

### Claude Code GitHub Actions v1.0.172
[Release Notes](https://github.com/anthropics/claude-code-action/releases/tag/v1.0.172)

Critical fix: steps now properly fail when SDK returns `is_error:true` regardless of `success` subtype. Previously allowed silent failures in CI/CD pipelines.

**Why it matters:** Update to v1.0.172+ immediately if you rely on GitHub Actions for PR validation—earlier versions may pass CI despite agent errors.

---

### GitHub Actions Migration (Beta → v1)
[Documentation](https://code.claude.com/docs/en/github-actions)

Breaking changes for GA release:
- Update workflows from `@beta` to `@v1`
- Replace `direct_prompt` with `prompt` input
- Move CLI options (`max_turns`, `model`, `custom_instructions`) to `claude_args` parameter
- Auto-detection removes manual mode configuration

**Why it matters:** Beta workflows will stop working when beta tag is sunset; migrate now to avoid CI breakage.
