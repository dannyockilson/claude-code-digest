## 🚨 Breaking Changes & Action Required

**[Claude Code v2.1.217](https://github.com/anthropics/claude-code/releases/tag/v2.1.217) — Security & Concurrency Limits**  
Subagent nesting depth reduced from 5 to 1 by default to prevent unbounded fan-out; concurrent subagent cap now 20 (configurable via `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`). Critical security fix: background session isolation now canonicalizes symlinked working directories, preventing workspace containment bypass. Memory leak fix for truncated MCP tool outputs that retained full results in memory.  
**Why it matters:** If you rely on deep subagent nesting (>1 level), set `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH` env var immediately. Symlink canonicalization closes a significant sandbox escape vector.

**[Agent SDK Python v0.2.124](https://github.com/anthropics/claude-agent-sdk-python/releases/tag/v0.2.124) — Windows Command Injection Fix**  
Blocks dangerous `.bat`/`.cmd` spawning on Windows (CVE-2024-27980 class) to prevent command injection via cmd.exe metacharacter re-parsing. Windows npm shim users must switch to native installer or explicit `claude.exe` path. Also hardens `resume`/`session_id` validation.  
**Why it matters:** Windows users on npm shims will break on upgrade—plan migration to native installer or hardcoded paths.

**[MCP TypeScript SDK v2.0.0-beta.5](https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/%40modelcontextprotocol/server%402.0.0-beta.5) — Wire Protocol Breaking Change**  
`DiscoverResult.serverInfo` moved to response `_meta['io.modelcontextprotocol/serverInfo']`; `RequestMetaEnvelope.clientInfo` now optional. Aligns with final MCP spec PR #3002 (2026-07-28 wire). Fixes critical interop issue where SDK rejected conforming servers (go-sdk v1.7.0+). Servers now stamp `_meta` on all 2026-era responses including `subscriptions/listen`.  
**Why it matters:** MCP server/client implementers must update before servers start using 2026 wire format—existing code will hard-reject conforming servers.

**[Agent SDK TypeScript v0.3.217](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.217) — Subagent Nesting Reduced**  
Subagent nesting depth reduced from 5 to 1 by default (override with `CLAUDE_CODE_MAX_SUBAGENT_SPAWN_DEPTH`); concurrent subagent limit now 20 (configurable via `CLAUDE_CODE_MAX_CONCURRENT_SUBAGENTS`). Fixed Remote Control permission prompt delivery for late-joining clients.  
**Why it matters:** Workflows with nested agent patterns will fail silently at depth >1 unless env var set.

## 🆕 New Releases

**[Claude Code v2.1.219](https://github.com/anthropics/claude-code/releases/tag/v2.1.219) — Opus 5 Default + Network Sandboxing**  
Claude Opus 5 now default model with 1M context window and pricing at $10/$50 per Mtok—enables longer code sessions without model switching. New `sandbox.network.strictAllowlist` setting for zero-prompt network access control in sandboxed commands. Subagent nesting expanded to depth-3 (was depth-1 in prior release). Fixed critical bug where approved permissions dropped on self-hosted runner restart.  
**Why it matters:** 80% price drop on output tokens + 1M context = fundamentally different economics for long debugging/development sessions.

**[Claude Code v2.1.218](https://github.com/anthropics/claude-code/releases/tag/v2.1.218) — Background Subagents + Windows Path Fix**  
`/code-review` now runs as background subagent, keeping conversation clean and preserving slash command stacking. Critical fix for Windows paths with `\u` segments (e.g., `C:\Users\unicorn`) being corrupted to CJK characters. `/ultrareview` now accepts descriptive arguments like "review my auth changes" instead of requiring precise syntax. CLI quality-of-life fixes: left-arrow key confirms before discarding conversation; `/context` reports accurate post-compact token usage.  
**Why it matters:** Windows users were silently unable to access files in `\Users\*` paths—this was a showstopper bug.

**[Claude Code v2.1.216](https://github.com/anthropics/claude-code/releases/tag/v2.1.216) — Performance + OAuth Stability**  
Critical performance fix: resolved quadratic message normalization slowdown causing multi-second stalls in long sessions. OAuth stability: fixed auto mode hanging on expired tokens mid-session and 403-looping on reconnect. Added `sandbox.filesystem.disabled` setting to skip isolation while maintaining network egress control. 20+ UX/stability fixes for prompt stalls, session state corruption, background agent restoration, and terminal rendering.  
**Why it matters:** Quadratic normalization bug directly impacted daily CLI usage—long sessions became unusable with multi-second freezes.

**[Anthropic SDK Python v0.120.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v0.120.0) — Opus 5 + Tool Management**  
Claude Opus 5 model available in SDK v0.120.0 with `claude-opus-5` identifier. New tool management: addition/removal blocks and `tool_change` events for dynamic tool orchestration. Enhanced fallback credit tokens with expanded client-side types + server-side fallbacks default option.  
**Why it matters:** Dynamic tool orchestration enables runtime tool modification without conversation restart—opens up adaptive agent patterns.

**[Anthropic SDK TypeScript v0.115.0](https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/sdk-v0.115.0) — Opus 5 + Memory Leak Fix**  
`claude-opus-5` model added. Tool lifecycle management via new tool addition/removal blocks and `tool_change` events. Fallback credit tokens expanded. Memory leak fix: abort listeners now properly released when requests settle.  
**Why it matters:** Memory leak in long-running processes (e.g., servers handling many Claude API calls) is now fixed.
