## 🚨 Breaking Changes & Action Required

### [Claude Code v2.1.233](https://github.com/anthropics/claude-code/releases/tag/v2.1.233)
MCP v2 connection stability fixed—prevents endless subscription stream reopening on serverless hosts with timeouts. Security fix for Windows NT device prefix paths (`\??\`) closes NTLM credential-leak vector. New `CLAUDE_CODE_TOOL_MEMORY_LIMIT` env var enables optional memory cgroup isolation for Bash commands on Linux to prevent runaway builds from stalling sessions.  
**Why it matters:** Resolves silent session deaths on Lambda/Cloud Run and eliminates Windows credential theft risk.

### [Claude Code v2.1.231](https://github.com/anthropics/claude-code/releases/tag/v2.1.231)
Fixed critical MCP OAuth sign-in bug where redirect URI mismatches prevented authentication with pre-registered OAuth clients like Slack.  
**Why it matters:** Unblocks OAuth-based MCP server integrations—immediate upgrade if you hit auth failures.

### [Claude Code v2.1.229](https://github.com/anthropics/claude-code/releases/tag/v2.1.229)
SSE keepalive pings now prevent idle-timeout disconnects on Vertex/Bedrock during long thinking pauses. Plugin marketplace now supports dynamic command sources via `mode: "link"` without restart. Multiple crash fixes including narrow terminal RangeError and Windows extended-length path handling.  
**Why it matters:** Fixes silent session deaths on cloud providers and eliminates restart friction for plugin workflows.

### [Anthropic SDK Python v0.122.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v0.122.0)
Critical streaming fixes for message accumulation and tool input JSON handling. AWS/Bedrock SigV4 signing now runs off event loop in async clients, resolving concurrency issues. Empty credential edge cases patched.  
**Why it matters:** Directly impacts reliability of production streaming workflows—update if you see malformed tool inputs or async hangs.

### [Anthropic SDK TypeScript (Vertex) v0.19.2](https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/vertex-sdk-v0.19.2)
**Security critical:** Fixes ambient first-party credentials being inadvertently sent to Vertex/Bedrock provider endpoints.  
**Why it matters:** Credential leakage to external providers—update immediately if using AWS Bedrock or Google Vertex AI.

### [Anthropic SDK TypeScript (Bedrock) v0.32.2](https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/bedrock-sdk-v0.32.2)
**Security critical:** Prevents ambient first-party credentials from being sent to provider endpoints.  
**Why it matters:** Review credential handling if using implicit/ambient authentication with Vertex/Bedrock.

### [Claude Agent SDK Python v0.2.137](https://github.com/anthropics/claude-agent-sdk-python/releases/tag/v0.2.137)
**Breaking:** `ConversationResetMessage` added to `Message` union—code using `assert_never` pattern needs updates to handle `/clear` and transcript-reset events. New `origin` field on messages distinguishes human prompts from background tasks. Safe session resume with truncation options added.  
**Why it matters:** Type guards will break—update exhaustive matching code before v0.3.

### [Claude Agent SDK TypeScript v0.3.233](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.233)
**Breaking:** Todo/task-tracking tools removed from default tool surface in Opus 4.8+, Sonnet 5+—explicitly enable via `tools` option, `allowedTools`, or `CLAUDE_CODE_ENABLE_TODO_TOOLS=1`.  
**Why it matters:** Workflows relying on task tracking will silently lose functionality—check your tool configurations.

## 📄 Docs Changes

### [Claude Code Hooks Guide](https://code.claude.com/docs/en/hooks-guide)
Expanded with 6 practical examples: desktop notifications when Claude needs input (macOS/Linux/Windows), auto-format with Prettier post-edit (PostToolUse event), block edits to protected files via PreToolUse hooks, re-inject context after conversation compaction (SessionStart hook).  
**Why it matters:** Enables no-code automation for common workflow patterns—notifications eliminate terminal watching.

### [Claude Code GitHub Actions](https://code.claude.com/docs/en/github-actions)
Quick setup now uses `/install-github-app` command to automate GitHub App installation and secret configuration. Review workflow posts inline comments directly on PRs (v2.1.229+). Added workload identity federation via OIDC token exchange—eliminates long-lived API secrets.  
**Why it matters:** Setup time reduced from manual multi-step process to single command—OIDC support improves security posture.

### [Claude Code MCP](https://code.claude.com/docs/en/mcp)
Clarifies four transport options (HTTP/SSE/stdio/WebSocket) with specific use cases. Breaking change in v2.1.202+: JSON entries with `url` but no `type` field now require explicit `type` specification. New `CLAUDE_PROJECT_DIR` environment variable passed to stdio servers. Workspace trust model introduced (v2.1.196+): project-scoped MCP servers require interactive approval in untrusted folders.  
**Why it matters:** Workspace trust model prevents malicious MCP servers in cloned repos—review trust settings for security.
