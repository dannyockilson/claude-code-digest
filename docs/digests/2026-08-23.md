## 🚨 Breaking Changes & Action Required

### [Claude Code v2.1.239 Bedrock Billing Fix](https://github.com/anthropics/claude-code/releases/tag/v2.1.239)
Fixed critical streaming bug behind proxies that silently doubled API costs by re-running every turn non-streaming when Content-Type headers were stripped. **Action:** Bedrock users behind proxies should audit recent billing for duplicate charges and upgrade immediately.

**Why it matters:** Silent double-billing could have caused significant unexpected costs for production deployments.

### [Anthropic Python SDK v1.0.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.0.0)
Breaking change: httpx2 upgrade requires migration for custom HTTP client configurations. See MIGRATION.md for transport setting updates. Streaming event imports reorganized—verify import paths reference `lib/streaming/_types.py`.

**Why it matters:** First stable v1.0 release, but breaks existing code using custom HTTP clients or transport configs.

### [Claude Code Action v1.0.196](https://github.com/anthropics/claude-code-action/releases/tag/v1.0.196)
Security fix: unified secret redaction in public PR comments prevents credential leaks. Removed ALL_INPUTS environment variable from Claude subprocess to reduce attack surface.

### [Claude Code Action v1.0.194](https://github.com/anthropics/claude-code-action/releases/tag/v1.0.194)
Breaking: `delete_files` MCP tool now validates paths must stay within repo root—may reject previously-allowed deletions outside scope. Security bump: shell-quote 1.8.4 remediates CVE-2026-9277.

### [Claude Code v2.1.234 — Auto-Resume & Security Hardening](https://github.com/anthropics/claude-code/releases/tag/v2.1.234)

Docs refresh emphasizes terminal CLI as primary interface with native install paths (macOS/Linux/WSL, Homebrew, WinGet). ### [Hooks Guide — Lifecycle Automation](https://code.claude.com/docs/en/hooks-guide)
Claude Code now supports Hooks for lifecycle automation: desktop notifications when Claude needs input, auto-formatting with Prettier on file edits, blocking edits to protected files. Hook configuration lives in `~/.claude/settings.json` with event-based triggers. New `/hooks` CLI command opens browser showing all available events. Production-ready examples included for context re-injection, config auditing, and auto-approval workflows.

**Why it matters:** Hooks unlock powerful workflow customization without SDK code; enables teams to enforce policies and automate repetitive tasks.

### [GitHub Actions — Quick Setup Workflow](https://code.claude.com/docs/en/github-actions)
Docs expanded with `/install-github-app` command automating GitHub App installation, secret configuration, and workflow PR creation. Review workflow now posts inline PR comments instead of only logs (v2.1.229+). Organization-level rollout guidance added for multi-repo deployments.

### [MCP Documentation — Breaking Change Clarification](https://code.claude.com/docs/en/mcp)
HTTP servers now require explicit `type: "http"` field; missing `type` is configuration error (v2.1.202+), not silent fallback. New `CLAUDE_PROJECT_DIR` environment variable stabilizes project root for stdio servers. Anthropic Directory integration documented: browse reviewed MCP connectors and use `claude mcp add` with transport flags.
