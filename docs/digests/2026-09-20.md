# Claude Code Weekly Intelligence Digest

## This Week's Highlights

A critical production bug in v2.1.275 (proxy configuration failures) was patched in v2.1.276 within hours—upgrade immediately if you use `ANTHROPIC_BASE_URL`. The server-side auto mode classifier is now default across all platforms, eliminating classifier overhead charges for most users. Agent SDK updates fix session state corruption that broke cost tracking and tool result serialization, while MCP startup no longer blocks first turns by default.

## 🚨 Breaking Changes & Action Required

**[Claude Code v2.1.276](https://github.com/anthropics/claude-code/releases/tag/v2.1.276)** — Proxy configuration hotfix  
Resolves v2.1.275 regression where all requests failed with `400 Input tag 'advisor_20260301'` when using `ANTHROPIC_BASE_URL`. If you run Claude Code behind a proxy or gateway, upgrade immediately.

**[Claude Code v2.1.278](https://github.com/anthropics/claude-code/releases/tag/v2.1.278)** — Server-side classifier now default  
Auto mode now uses server-side classification for Claude API, Enterprise, Bedrock, Vertex, Foundry, and gateways—eliminating classifier overhead charges. Fallback to billed classifier now warns users. Check `/status` row to confirm which classifier your session uses. Opt out with `CLAUDE_CODE_AUTO_MODE_SERVER=0` if needed.

**[Claude Code v2.1.276 AGENTS.md fallback](https://github.com/anthropics/claude-code/releases/tag/v2.1.277)** — Multi-agent project support  
Claude Code now reads `AGENTS.md` when `CLAUDE.md` is absent, configurable via `/config`. Not yet available on Bedrock/Vertex/Foundry. Update project documentation structure accordingly if running multi-agent workflows.

**[Claude Code v2.1.274](https://github.com/anthropics/claude-code/releases/tag/v2.1.274)** — MCP startup behavior change  
New `CLAUDE_CODE_MCP_STARTUP_WAIT_MS` env var controls MCP server connection wait on first turn (default: wait, set to `0` to skip). Improves startup performance for non-interactive workflows but may affect MCP tool availability timing.

**[Claude Code v2.1.273](https://github.com/anthropics/claude-code/releases/tag/v2.1.273)** — Permission checker bypass fixed  
Critical security fix: `permissions.blockReadsOutsideWorkingDirectories` now correctly blocks subshells hiding `rm` commands. Bash lines that can't be fully analyzed now re-prompt instead of being auto-denied.

**[Anthropic Python SDK v1.7.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.7.0)** — Rate limit API changes  
`group_type` deprecated in favor of `group` with `display_name`. Update monitoring/alerting logic if you parse rate limit headers. Also: Pydantic 1.10+ now required.

**[Anthropic TypeScript SDK v0.127.0](https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/sdk-v0.127.0)** — Rate limits breaking change  
Same rate limit API change as Python SDK. Also fixes critical stream handling bugs: null `compaction_delta` serialization, stream retries, and `anthropic-beta` header formatting.

## 🆕 New Releases

**[Claude Code v2.1.275](https://github.com/anthropics/claude-code/releases/tag/v2.1.275)** — Send-now key and skill sync  
Send-now key (`ctrl+enter`) interrupts current turn and queues messages for iterative coding sessions. Claude.ai skills/plugins now auto-sync to terminal sessions (opt-out via config). Extensive stability fixes for memory caching, subagent messaging, artifact restoration, and improved prompt caching with `__SYSTEM_PROMPT_DYNAMIC_BOUNDARY__`.

**[Claude Code v2.1.271](https://github.com/anthropics/claude-code/releases/tag/v2.1.271)** — Fast mode in Remote  
Fast mode (`/fast`) now available in Claude Code Remote sessions (cloud/self-hosted). Per-command `allowed_domains` for Bash/PowerShell restricts network access per-command instead of globally. CLI improvements: `claude plugin install/update --accept-command <sha256>` and mouse-scrollable `/config` panel.

**[Anthropic Python SDK v1.7.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.7.0)** — Context management tool  
New `compact_before_next_turn()` tool runner method for managing conversation state/memory, reducing context overhead in multi-turn interactions. Also: union type parsing fixes and async credential token providers.

**[Anthropic TypeScript SDK v0.127.0](https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/sdk-v0.127.0)** — TypeScript 6.0.3 upgrade  
Added `compactBeforeNextTurn()` to tool runner for history compaction. Upgraded to TypeScript 6.0.3 and migrated internal tests from jest to vitest. Bundle size optimizations with `"sideEffects": false`.

**[Anthropic TypeScript SDK v0.126.0](https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/sdk-v0.126.0)** — Message compaction beta  
Managed Agents auto mode tool permissions added. New `compaction` parameter and signed compaction blocks for reducing conversation history size. Improved retry/connection handling with proper `Retry-After` validation.

## 📦 SDK & API Updates

**[Claude Agent SDK Python v0.2.153](https://github.com/anthropics/claude-agent-sdk-python/releases/tag/v0.2.153)** — System prompt snapshots  
Added `snapshot` option for system prompts—when True, freezes on first request for better prompt-caching; when False, rebuilds on every request for iterative development. Bundled CLI updated to 2.1.273.

**[Claude Agent SDK TypeScript v0.3.277](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.277)** — Cost tracking fix  
Fixed critical bug where resumed/forked sessions lost cost tracking (`total_cost_usd`, `modelUsage`). Added `pasted_content` to `SDKUserMessage` for UX differentiation. Remote-session latency telemetry fields added.  
*Why it matters:* Accurate budget monitoring now works correctly across session resumes/forks.

**[Claude Agent SDK TypeScript v0.3.275](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.275)** — Tool result serialization fix  
Fixed tool result serialization using wrong key format (`toolUseResult` → `tool_use_result`), breaking deferred tool calls. Fixed `getSessionMessages()` and `forkSession()` dropping assistant messages and task notifications.  
*Why it matters:* Resumed sessions now maintain complete state across turns.

**[Claude Agent SDK TypeScript v0.3.274](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.274)** — MCP startup performance  
MCP servers no longer block first turn (removed 2s wait). Added `startup_failure_reason` and per-phase `startup_timing` breakdown. Fixed `getSessionMessages()` omitting user messages during tool execution.  
*Why it matters:* Faster session starts and better debugging for MCP integration issues.

**[Claude Agent SDK TypeScript v0.3.273](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.273)** — Usage reporting  
Added `usage_report` on assistant messages for headless `/usage` results. Fixed critical hook callback timeout handling and browser SSE transport dropping live slash-command updates.

**[Claude Agent SDK TypeScript v0.3.271](https://github.com/anthropics/claude-agent-sdk-typescript/releases/tag/v0.3.271)** — Subagent CLAUDE.md control  
Added `omitClaudeMd` option to `AgentDefinition` allowing subagents to skip loading user/project CLAUDE.md files. Fixed Windows path issues with mapped/SUBST drives. Removed `persistent` from `MonitorInput` tool type (breaking change).

**[skillranker](https://github.com/Dicklesworthstone/skillranker)** — Jev-powered skill ranking CLI  
Rust CLI that ranks agent skills dynamically using live session context via Jev. Integrates Claude Code hooks, outputs structured JSON, supports abstention logic.
