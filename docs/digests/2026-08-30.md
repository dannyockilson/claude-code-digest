## 🚨 Breaking Changes & Action Required

**[Claude Code v2.1.251](https://github.com/anthropics/claude-code/releases/tag/v2.1.251)** — Critical security vulnerabilities patched in file tools (symlink traversal in Read/Write/Edit), plugin paths, and Workflow tool that could read/write outside approved locations. Essential for users running untrusted code or in shared environments. Also added `PreModelSwitch`/`PostModelSwitch` hook events for intercepting model changes and live streaming of foreground subagent tool calls to Remote Control clients. Fixed 30+ stability issues including TUI lag with parallel subagents and background session plugin loading race conditions.

**[Claude Code v2.1.248](https://github.com/anthropics/claude-code/releases/tag/v2.1.248)** — New `--restricted` flag enables sandboxed execution by removing command/code tools and WebFetch, confining file operations to working directory, and blocking permission bypassing. Fixed prompt-cache misses losing extended-thinking context every ~1hr during long sessions caused by tool re-rendering post-OAuth refresh. Session persistence bugs resolved: desktop sessions survive 30-day cleanup, background worktree sessions hold locks, remote-control sessions properly reconnect.

**Why it matters:** The symlink vulnerabilities and credential leakage issues represent serious security risks in multi-tenant or CI/CD environments. The `--restricted` flag provides first-class support for secure agent deployments.

**[Claude Code v2.1.246](https://github.com/anthropics/claude-code/releases/tag/v2.1.246)** — **Breaking:** Bash wildcard rules now match options—`Bash(git * main)` now catches options inserted before subcommand; startup warning added to catch unsafe existing rules. Security fix: MCP tool calls no longer leak credentials to third-party gateways—telemetry/metrics requests now only send API keys to configured host. Auto mode classifier rules now editable in `/permissions` tab. Fixed severe transcript slowdown on diffs with long single lines.

**[Claude Code v2.1.245](https://github.com/anthropics/claude-code/releases/tag/v2.1.245)** — Fixed critical startup crash on Linux with glibc 2.44 (Arch Linux, CachyOS, Fedora Rawhide). Essential patch for users on rolling-release distros.

**[anthropic-sdk-python v1.2.0](https://github.com/anthropics/anthropic-sdk-python/releases/tag/v1.2.0)** — Files/Skills namespaces graduate from beta to GA shapes, removing dated header pins—**update your code if using these endpoints**. Critical fix for AWS/Bedrock binary file uploads now working correctly by signing raw request bytes. Tools improvements: file reading supports view_range for large files.

**Why it matters:** GA shape changes are breaking—any code using beta Files/Skills APIs must be updated to avoid runtime errors.

**[anthropic-sdk-typescript sdk-v0.122.0](https://github.com/anthropics/anthropic-sdk-typescript/releases/tag/sdk-v0.122.0)** — Files/Skills namespaces graduate from beta to GA shapes—**update imports if using beta headers**. Critical fix: SSE parse errors now respect configured logger instead of defaulting to console. Webhook security hardening: `unwrap()` now requires headers parameter to prevent validation bypass.
