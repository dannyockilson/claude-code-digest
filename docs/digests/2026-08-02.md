## 🚨 Breaking Changes & Action Required

### MCP Python SDK v2.0.0
https://github.com/modelcontextprotocol/python-sdk/releases/tag/v2.0.0

MCP Python SDK v2.0.0 is now stable and default on PyPI, implementing 2026-07-28 spec with backward compatibility for 2025-era clients. Breaking changes: `FastMCP` renamed to `MCPServer`, v1 transport layering replaced with unified `Client(target)` object, `Resolve(fn)` parameter injection for multi-round-trip requests, and stricter stdio handling. v1.x moves to maintenance mode (security fixes only).

**Why it matters:** Pin `mcp<2` if you're not ready to migrate production servers. New unified client API simplifies connection management but requires code changes.

### MCP TypeScript SDK @modelcontextprotocol/server@2.0.0
https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/%40modelcontextprotocol/server%402.0.0

Schema consolidation moves core schemas to `@modelcontextprotocol/core` package with shared object identity. Wire protocol breaking changes: `DiscoverResult.serverInfo` moves to response `_meta`, `RequestMetaEnvelope.clientInfo` now optional. Runtime-neutral auth/OAuth now works on web-standard fetch hosts (Cloudflare Workers, Deno, Bun, Hono).

**Why it matters:** Schema consolidation reduces memory overhead in multi-package apps, but requires updating type imports and cached era verdicts with new `PriorDiscovery` type.

### MCP TypeScript SDK @modelcontextprotocol/client@2.0.0
https://github.com/modelcontextprotocol/typescript-sdk/releases/tag/%40modelcontextprotocol/client%402.0.0

Response cache now stores JSON strings instead of object graphs, removing `structuredClone` dependency (fixes jest+jsdom compatibility). Custom `ResponseCacheStore` implementations must treat `CacheEntry.value` as `string`. `Protocol` and `mergeCapabilities` re-exported from package roots (v1 compatibility restored).

**Why it matters:** If you've built custom cache stores, you'll need to update serialization logic. JSON string storage improves compatibility but changes cache interface contracts.

### Claude Code GitHub Actions v1 GA
https://code.claude.com/docs/en/github-actions

Replace `@beta` with `@v1` in workflows. Unified API: replace `direct_prompt` with `prompt` input, move CLI options (max_turns, model, custom_instructions) to `claude_args` parameter. Manual mode configuration removed (now auto-detected). New cloud provider support: Amazon Bedrock and Google Cloud's Agent Platform with Workload Identity Federation.

**Why it matters:** Beta workflows will break. Migration required for GitHub Actions users, but GA brings enterprise data residency options via Bedrock/GCP.

Official stable release of MCP specification with detailed changelog at modelcontextprotocol.io. This is the spec version implemented by Python SDK v2.0.0 and TypeScript SDK v2.0.0.

### MCP Python SDK v2.0.0rc1
https://github.com/modelcontextprotocol/python-sdk/releases/tag/v2.0.0rc1

Major API cleanup before stable release. Breaking changes: `Client(cache=False)` → `Client(cache=None)`, `Context.client_id` removed, OAuth provider renames. Full 2026-07-28 spec support over stdio including subscriptions/listen.

**Why it matters:** RC1 fixed critical stdio isolation bugs. If you're hitting Windows hangs or wire corruption, this release solves them.

## 📄 Docs Changes

### Claude Code Hooks Guide
https://code.claude.com/docs/en/hooks-guide

Documentation updated with practical automation patterns. PreToolUse/PostToolUse hooks enable file protection and auto-formatting (e.g., block .env edits, auto-run Prettier). SessionStart/CwdChanged hooks reload environment variables dynamically—critical for direnv/devbox users. PermissionRequest hooks auto-approve specific tool calls with JSON decision output. New matcher syntax requires Claude Code v2.1.198+.

**Why it matters:** Hooks unlock powerful automation—file protection and auto-formatting reduce manual intervention in agentic workflows.

### Claude Code MCP
https://code.claude.com/docs/en/mcp

CLAUDE_PROJECT_DIR environment variable now stable across sessions and exposed to stdio MCP servers (v2.1.203+), enabling reliable project-relative path resolution. roots/list MCP request returns all working directories with change notifications (v2.1.203+). HTTP transport accepts streamable-http alias. Workspace trust model refined: .mcp.json servers require explicit approval in untrusted folders.

**Why it matters:** CLAUDE_PROJECT_DIR stability simplifies MCP server path handling—no more brittle relative path workarounds.

### MCP Specification
https://modelcontextprotocol.io/specification

Documentation now emphasizes security and trust/safety as first-class concerns with explicit user consent requirements. Core protocol unchanged (JSON-RPC, stateless requests) but security section clarified: hosts must obtain explicit consent before exposing user data to servers or invoking tools. Extensions formalized (Tasks, Skills over MCP, MCP Apps) as opt-in.

**Why it matters:** Security requirements codified—affects how MCP servers should implement consent flows and access controls.
